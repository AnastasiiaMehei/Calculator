# 📐 Calculator Vue

Simple Calculator Application built with **Vue 3**, **TypeScript**, **Vite**, and styled using **Bootstrap 5**.  
The app features a modern glassmorphism UI with background image, hover animations, and advanced math functions.

## 🚀 Features
- Basic operations: `+`, `-`, `*`, `/`, `^`
- Advanced math functions: `sqrt`, `cbrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `ln`, `log`
- Constants: `π` and `e`
- Parentheses support for formulas
- Clear (`C`) and Delete functionality
- Responsive design with **Bootstrap 5**
- Glassmorphism UI with blur and hover effects
- Custom scrollbar styling
- Background image support

---

## 🛠️ Tech Stack
- **[Vue 3](https://vuejs.org/)** — reactive UI framework
- **[Vite](https://vitejs.dev/)** — fast build tool
- **[TypeScript](https://www.typescriptlang.org/)** — type safety
- **[Bootstrap 5](https://getbootstrap.com/)** — responsive styling

## ⚙️ Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/calculator-vue.git
cd calculator-vue
npm install
▶️ Development
Run the app in development mode:

bash
npm run dev
📦 Build
Create a production build:

bash
npm run build
Preview the production build locally:

bash
npm run preview
